# Model Management

## Overview

This directory contains documents related to the management and tracking of production models used in the Seafood Freshness Classification project.

It serves as a centralized repository for maintaining the release history of deployed models and documenting the training datasets used for the current production models.

## Contents

* **Model Version History** – Records the evolution of production models across different seafood species, including:

  * Model name and version
  * Major changes introduced
  * Update date
  * Testing date

* **Current Model Training Dataset** – Documents the dataset distribution used to train the currently deployed production models for each seafood species.

## Purpose

The files in this directory provide traceability for production models by documenting:

* Model version history
* Architecture and feature updates
* Production release timeline
* Training dataset composition of the current deployed models

This information supports model maintenance, deployment tracking, reproducibility, and knowledge transfer.

> **Note:** This folder contains production model management documents only. Model training code, research experiments, evaluation results, and trained weights are maintained in their respective project directories.
