# Dataset Analysis

## Overview

This directory contains notebooks used to analyze the collected seafood datasets and generate metadata, statistics, and reports.

The analysis is performed on metadata generated during the data collection process, eliminating the need to repeatedly download and scan the complete image dataset.

The generated outputs are stored in the `generated-files/` directory and are used throughout the project for exploratory data analysis, dataset monitoring, and experiment planning.

---

## Directory Contents

### `create_complete_data_df_with_reasons.ipynb`

Creates a unified metadata file for the entire seafood dataset by combining data collected from AWS S3 and manually collected images.

**Requirements**

* `generated-files/reasons based dataset.csv`

  * Generated by `../Data Collection/reason-based-data.ipynb`

**Workflow**

1. Loads the reason-based metadata.
2. Creates metadata for images stored in AWS S3.
3. Creates metadata for manually collected images.
4. Combines both sources into a single dataset.
5. Skips previously processed images to reduce processing time.
6. Saves the final metadata file.

**Generated Files**

* `complete data.csv`
* `manual data.csv`

The resulting metadata contains information such as:

* Collection Date
* Species
* Freshness Label
* Rejection Reason
* AWS S3 File Key

This consolidated metadata enables fast filtering and analysis by date, species, freshness class, and rejection reason without requiring access to the original image dataset.

**Notes**

* The notebooks operate primarily on metadata rather than image files, making dataset analysis significantly faster.
* Generated metadata serves as the central source for exploratory analysis and reporting throughout the project.
---

### `Dataset.ipynb`

Generates statistical summaries and visualizations of the collected datasets.

**Requirements**

Dataset directory organized as:

```text
date/
└── species/
    ├── Good/
    └── Bad/
```

**Features**

* Dataset distribution analysis
* Date-wise image statistics
* Date range analysis
* Species-wise statistics
* Misclassified image analysis
* Good vs Bad distribution
* Single vs Group distribution
* Visualization using bar charts
* Export of dataset statistics

**Generated Files**

* `Dataset_distribution.xlsx`

The generated report contains statistics including:

* Good Single
* Good Group
* Bad Single
* Bad Group
* Total Good
* Total Bad
* Total Single
* Total Group
* Misclassified Images
