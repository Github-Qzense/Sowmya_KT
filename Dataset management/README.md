# Dataset Management

## Overview

This module contains the complete dataset engineering pipeline for the Seafood Freshness Classification project.

It covers the entire lifecycle of the dataset, including data collection, organization, metadata generation, statistical analysis, and post-deployment application testing.

The tools in this module ensure that high-quality, well-organized datasets are available for training, evaluating, and improving the computer vision models used throughout the project.

---

## Module Structure

```text
Dataset Management/
```

## Directory Description

### `Data Collection`

Contains notebooks and utilities for collecting, organizing, cleaning, and preparing seafood image datasets from multiple sources, including AWS S3 and manually collected images.

---

### `Dataset Analysis`

Contains tools for generating metadata, dataset statistics, visualizations, and reports used throughout the research and model development process.

---

### `generated-files`

Stores metadata files, reports, spreadsheets, and other outputs generated by the data collection and analysis pipelines.

---

### `docs`

Project documentation related to dataset management, data handling procedures, and supporting reports.

---

## Key Features
